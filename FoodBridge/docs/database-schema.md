# Database schema

Tables are generated by Hibernate from the entities in `com.foodbridge.entity` (`spring.jpa.hibernate.ddl-auto=update`). For MySQL run `src/main/resources/db/init.sql` first to create the schema and user.

| Table | Purpose | Key columns / constraints |
|---|---|---|
| `users` | Every account | `email` UNIQUE, `password_hash` (BCrypt), `role` (DONOR, RECIPIENT, VOLUNTEER, ADMIN), `status` (ACTIVE, SUSPENDED), index on `role` |
| `organization_profiles` | Business (donor) / NGO details | `user_id` UNIQUE FK, `organization_name`, `address`, `preferred_categories` (CSV) |
| `volunteer_profiles` | Volunteer details | `user_id` UNIQUE FK, `vehicle_type`, `service_area`, `availability` |
| `food_donations` | Listings | `donor_id` FK, `quantity`, `remaining_quantity`, `status`, `pickup_deadline`, `version` (optimistic lock); indexes `(status, pickup_deadline)`, `category`, `city`, `donor_id` |
| `donation_requests` | Recipient requests | `donation_id` FK, `recipient_id` FK, `quantity`, `status`, snapshots of recipient name and drop-off address; indexes on donation, recipient, status |
| `pickup_assignments` | Delivery tasks | `request_id` UNIQUE FK, `volunteer_id` FK (nullable until accepted), `status`, timestamps |
| `notifications` | In-app messages | `user_id` FK, `is_read`; index `(user_id, is_read)` |
| `audit_logs` | Append-only trail | `actor_id`, `actor_email`, `action`, `entity_type`, `entity_id`; no FK on purpose |

Every table also has `id`, `created_at`, `updated_at`.

## Status values

* Donation: `AVAILABLE`, `RESERVED`, `COMPLETED`, `EXPIRED`, `DISABLED` (admin), `WITHDRAWN` (donor)
* Request: `PENDING` -> `ACCEPTED` | `REJECTED` | `CANCELLED`; `ACCEPTED` -> `COMPLETED` | `CANCELLED`
* Delivery: `OPEN` -> `ASSIGNED` -> `PICKED_UP` -> `IN_TRANSIT` -> `DELIVERED` (`CANCELLED` possible before pickup)

## Quantity rules

* Creating a donation: `remaining_quantity = quantity`.
* Accepting a request: `remaining_quantity -= request.quantity` (rejected if it would go below 0).
* Cancelling an accepted request before pickup: `remaining_quantity += request.quantity`.
* Editing a donation: new quantity cannot be lower than `quantity - remaining_quantity` (the reserved part).
